# Charlemos 3.3.0-beta.9 — Clean video-shape shell and conversion guidance

Testing only. This opt-in prerelease is not a stable update.

## Install or update

Use the beta manifest in a separate Foundry installation/data directory with a backed-up test world:

https://raw.githubusercontent.com/HonzoNebro/Charlemos-Camera-Layout/preview/ux-editor/module.json

The module ID is unchanged: installing this beta replaces stable Charlemos in that installation. The stable main manifest and Foundry listing remain unchanged.

## Change since beta.8

- A configured video crop removes the native Foundry camera shell, border, pseudo-elements and shadow that could remain around the visible shape. Camera controls stay available.
- The visual editor explains that converting to absolute positioning removes a relative anchor, while converting geometry to pixels retains the current layout mode and any relative anchor.

The automated quality suite passes. Confirm cropped feeds with and without a transparent frame, and conversion behaviour for absolute and relative layouts, in Foundry before stable promotion.

## Return to stable

Reinstall from https://raw.githubusercontent.com/HonzoNebro/Charlemos-Camera-Layout/main/module.json in the test installation. Restore the backed-up world to undo saved test configuration.
