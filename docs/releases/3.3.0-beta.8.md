# Charlemos 3.3.0-beta.8 — Mirrored video crop correction

Testing only. This opt-in prerelease is not a stable update.

## Install or update

Use the beta manifest in a separate Foundry installation/data directory with a backed-up test world:

https://raw.githubusercontent.com/HonzoNebro/Charlemos-Camera-Layout/preview/ux-editor/module.json

The module ID is unchanged: installing this beta replaces stable Charlemos in that installation. The stable main manifest and Foundry listing remain unchanged.

## Change since beta.7

- Guided circle, ellipse, inset and four-point polygon crops compensate for Foundry's native mirrored-video transform. The side or point shown in the editor remains on that visible side of the feed.
- Expanded frame viewports keep their internal overflow clipping but no longer duplicate the configured `clip-path` over the video.

The automated quality suite passes. Confirm right-only and left-only inset crops, polygon points and expanded frames with a mirrored live camera in Foundry before stable promotion.

## Return to stable

Reinstall from https://raw.githubusercontent.com/HonzoNebro/Charlemos-Camera-Layout/main/module.json in the test installation. Restore the backed-up world to undo saved test configuration.
