# Charlemos 3.3.0-beta.5 — Unified editor wording fix

Testing only. This opt-in prerelease is not a stable update.

## Install or update

Use the beta manifest in a separate Foundry installation/data directory with a backed-up test world:

https://raw.githubusercontent.com/HonzoNebro/Charlemos-Camera-Layout/preview/ux-editor/module.json

The module ID is unchanged: installing this beta replaces stable Charlemos in that installation. The stable main manifest and Foundry listing remain unchanged.

## Change since beta.4

The setting that opens Charlemos now correctly describes the unified editor in English, Spanish and Galician. It no longer says that configuration opens several dedicated windows.

Foundry 14.362 smoke validation confirmed that the editor opens and that a player-view circular crop remains a local draft until Apply. A draft created during that validation was not applied. Full Foundry 13.351/14.361, two-client, A/V, accessibility and GPU validation is still pending.

## Return to stable

Reinstall from https://raw.githubusercontent.com/HonzoNebro/Charlemos-Camera-Layout/main/module.json in the test installation. Restore the backed-up world to undo saved test configuration.
