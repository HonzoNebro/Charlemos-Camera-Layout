# Charlemos 3.3.0-beta.7 — Independent crops and native video transforms

Testing only. This opt-in prerelease is not a stable update.

## Install or update

Use the beta manifest in a separate Foundry installation/data directory with a backed-up test world:

https://raw.githubusercontent.com/HonzoNebro/Charlemos-Camera-Layout/preview/ux-editor/module.json

The module ID is unchanged: installing this beta replaces stable Charlemos in that installation. The stable main manifest and Foundry listing remain unchanged.

## Change since beta.6

- New Inset crops start at zero on each side with no rounding. New Polygon crops start as the complete camera rectangle. Adjusting one control no longer retains a default crop on its opposite edge.
- Video transformations keep Foundry's original transform while Charlemos is active and restore it when Charlemos stops styling the view. This preserves native camera mirroring.
- Basic video-effect removal buttons share each slider row and are disabled at the default value. Returning an effect to its default removes its redundant saved token.

The automated quality suite passes. Confirm the independent inset/polygon controls and camera mirroring in Foundry before stable promotion.

## Return to stable

Reinstall from https://raw.githubusercontent.com/HonzoNebro/Charlemos-Camera-Layout/main/module.json in the test installation. Restore the backed-up world to undo saved test configuration.
