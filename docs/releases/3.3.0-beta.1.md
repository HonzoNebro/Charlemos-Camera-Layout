# Charlemos 3.3.0-beta.1 — UX editor preview

Testing only. This is a prerelease, not a stable update.

## Install explicitly

Use this manifest in a separate Foundry installation/data directory with a backed-up copy of your world:

https://raw.githubusercontent.com/HonzoNebro/Charlemos-Camera-Layout/preview/ux-editor/module.json

The beta uses the same module ID as stable Charlemos and replaces it within that installation. Merely using a second world in the same installation does not isolate the installed module files. The preview manifest follows this beta branch; the stable manifest on main is unchanged.

## What to test

- Unified Scene / Cameras / Tools panel, local drafts, preview and explicit shared Apply.
- Scene-switch protection, conflict handling and reviewed imports.
- Presets, copying, custom CSS preservation and visual camera/frame/name editing.
- Foundry 13.351 and 14.361, two clients, dock/popout/detached windows and A/V lifecycle.

Automated suite: 37 test files passing. In-Foundry visual, multi-client and resource-usage acceptance is still pending. See docs/UX_ACCEPTANCE.md in this tag for the checklist.

## Return to stable

Reinstall from https://raw.githubusercontent.com/HonzoNebro/Charlemos-Camera-Layout/main/module.json in your test installation. Do not rely on an automatic downgrade. Restore the backed-up world if you need to undo changes made while testing.

Please include Foundry build, browser, reproduction steps and the Tools → Diagnostics report when reporting issues. Review diagnostics for private information before sharing.
