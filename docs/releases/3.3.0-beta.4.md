# Charlemos 3.3.0-beta.4 — Role variants and guided editing

Testing only. This opt-in prerelease is not a stable update.

## Install or update

Use the beta manifest in a separate Foundry installation/data directory with a backed-up test world:

https://raw.githubusercontent.com/HonzoNebro/Charlemos-Camera-Layout/preview/ux-editor/module.json

The module ID is unchanged: installing this beta replaces stable Charlemos in that installation. A second world alone does not isolate module files. The stable main manifest and Foundry listing remain unchanged.

## Changes since beta.3

- Shared base plus optional GM/player viewer-role variants, with sparse inheritance, the same forms/visual editor, local audience preview and undo. Roles refer to the viewer, not the camera owner, and are not a privacy boundary.
- Compatible role variants in templates, scene duplication, new macros and JSON v2. Old macros keep updating the base without removing existing variants. No automatic world migration.
- Guided crop parameters for compatible circles, ellipses and insets, an illustrative preview, and explicit replacement of custom shapes.
- Six frame rectangle alignment actions that include expanded bounds, rotation and scale without resizing the video. Simple offset units are retained; custom expressions require explicit conversion.
- English, Spanish and Galician help, deterministic style regression snapshots, lifecycle stress tests and non-publishing quality CI for Node 20/22.
- Completed pseudo-tile feasibility evaluation. Positioned live-camera tiles are not included; that roadmap item was an evaluation, not an implementation commitment.

Automated verification passes across 44 test files. Real Foundry 13.351/14.361 visual, multi-client, accessibility and GPU acceptance remains pending. This beta is provided to perform those checks, not as proof they have passed.

## Focused checks

Compare two connected viewers (GM/player), switch editing and preview audiences, reset inheritance and undo. Verify that changes stay local until Apply and existing macros still work. Align an asymmetric transparent frame after rotation/scale in dock and popout views. Confirm A/V controls and playback remain intact, and custom clip paths/offsets survive unrelated edits.

The full checklist is in `docs/UX_ACCEPTANCE.md`.

## Return to stable

Reinstall from https://raw.githubusercontent.com/HonzoNebro/Charlemos-Camera-Layout/main/module.json in the test installation. Do not rely on automatic downgrade. Restore the backed-up world to undo saved test changes; retain a beta-aware backup/version to recover optional library and variant configuration that older versions may ignore.
