# Charlemos 3.3.0-beta.2 — short-term roadmap preview

Testing only. This prerelease is opt-in and is not a stable update.

## Install or update the beta

Use the same preview manifest in a separate Foundry installation/data directory with a backed-up test world:

https://raw.githubusercontent.com/HonzoNebro/Charlemos-Camera-Layout/preview/ux-editor/module.json

The module ID is unchanged: this replaces stable Charlemos within that installation. A second world in the same data directory does not isolate installed module files. The stable main manifest and Foundry listing are unchanged.

## Changes since beta.1

- Quick frame presets and explicit Normal / Screen / Soft light blending with local preview and one-step undo. Automatic preserves legacy behavior.
- Saved composition listing, reviewed duplication into a destination draft and clearer macro naming.
- One-click diagnostic JSON downloads and English/Spanish/Galician troubleshooting guides.
- Reactive avatar listener cleanup and reversible collapsed video-container sizing fallback.

These changes complete the short-term roadmap implementation. The persistent template library, role-based variants and other long-term proposals are explicitly deferred.

Automated suite: 39 test files passing. Real Foundry 13.351 / 14.361 visual, multi-client and resource-usage acceptance remains pending; see docs/UX_ACCEPTANCE.md. No claim of complete visual compatibility is made from unit tests alone.

## Return to stable

Reinstall from https://raw.githubusercontent.com/HonzoNebro/Charlemos-Camera-Layout/main/module.json in the test installation; do not rely on an automatic downgrade. Restore the backed-up world if you need to revert saved test changes.

Include Foundry build, browser, reproduction steps and a reviewed diagnostic report when reporting issues. Reports may contain names, IDs, file paths and draft/saved settings; no camera frames or audio are included and downloading does not upload them anywhere.
