# Charlemos 3.3.0-beta.3 — Composition library preview

Testing only. This is an opt-in prerelease, not a stable update.

## Install or update

Use the existing beta manifest in a separate Foundry installation/data directory with a backed-up test world:

https://raw.githubusercontent.com/HonzoNebro/Charlemos-Camera-Layout/preview/ux-editor/module.json

The same module ID is retained: installing the beta replaces stable Charlemos in that installation. A second world does not isolate module files. The stable main manifest and Foundry listing remain unchanged.

## Changes since beta.2

- World-shared composition library under Tools, with named templates saved from persisted configuration or a valid draft.
- Explicit create, replace, rename and delete actions with confirmation and concurrent-change protection.
- Load templates into scene drafts with explicit user-ID mapping, local preview and one-step undo. Backgrounds and destination-only cameras remain unchanged.
- Optional JSON v2 library backup/import support. Older backups without the library block do not clear templates.
- English, Spanish and Galician interface/help and expanded automated coverage.

Templates are snapshots, not live links. Editing or deleting one does not update scenes that already used it. Library writes are shared immediately after confirmation, separate from applying a scene; scene Cancel does not undo them.

Automated suite: 40 test files passing. Manual Foundry 13.351 / 14.361 visual and multi-client acceptance remains pending. Role-based variants are not included.

## Return to stable

Reinstall from https://raw.githubusercontent.com/HonzoNebro/Charlemos-Camera-Layout/main/module.json in the test installation. Do not rely on an automatic downgrade. Restore the backed-up world to undo saved test changes. Older versions may ignore the optional library block; retain a library-aware backup and version to recover templates.
