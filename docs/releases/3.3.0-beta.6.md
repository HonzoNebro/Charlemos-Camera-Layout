# Charlemos 3.3.0-beta.6 — Focused visual editing and crop previews

Testing only. This opt-in prerelease is not a stable update.

## Install or update

Use the beta manifest in a separate Foundry installation/data directory with a backed-up test world:

https://raw.githubusercontent.com/HonzoNebro/Charlemos-Camera-Layout/preview/ux-editor/module.json

The module ID is unchanged: installing this beta replaces stable Charlemos in that installation. The stable main manifest and Foundry listing remain unchanged.

## Change since beta.5

- Visual editing is presented only where it applies: Camera in Position and size, Frame in Frame / overlay, and Name in Name. Video and effects no longer repeats the visual editor controls.
- Every selected crop has an illustrative preview. Circle, ellipse and inset retain direct controls; the bundled four-point polygon now exposes X/Y fields for all four points.
- Custom `clip-path` CSS keeps its value and receives a preview with a clear indication that its raw values remain in Advanced.

The automated quality suite passes. Manual Foundry acceptance remains required, particularly for the polygon preview and the scoped visual-editor controls in Foundry 13/14.

## Return to stable

Reinstall from https://raw.githubusercontent.com/HonzoNebro/Charlemos-Camera-Layout/main/module.json in the test installation. Restore the backed-up world to undo saved test configuration.
